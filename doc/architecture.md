Purpose: A handheld engineering device interfacing and controlling a Windows PC

PC companion: Responsible for telemetry collection, file management, input processing, and communication

Raspberry Pi: Responsible for GUI, touchscreen, physical controls, and displaying PC information

Communication: Wireless communcation between the two devices, with USB connectivity as an additional interface

Design ideals: Keep the Pi's software light and divide responsibilities between the two devices.
    This is mainly because the Pi has very little available memory and the PC's CPU/RAM is MUCH more powerful.
